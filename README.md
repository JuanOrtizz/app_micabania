# Proyecto Aplicacion Android MiCabaña
---
> MiCabaña es una aplicación móvil pensada para propietarios y administradores de propiedades en alquiler, como cabañas o casas, que necesitan llevar un control eficiente del inventario de objetos dentro de sus propiedades. Su diseño se enfoca en la facilidad de uso y accesibilidad, ideal para personas con poca experiencia tecnológica.
---
## Objetivos del Proyecto
---
- **Digitalizar el control de inventario:** Facilitar el seguimiento y control del inventario de propiedades de alquiler a través de una aplicación móvil.
- **Mejorar la accesibilidad y usabilidad:** Crear una solución accesible y sencilla para personas mayores o sin experiencia tecnológica.
- **Optimizar el manejo de stock por propiedad:** Permitir organizar objetos por categorías, ajustar cantidades y eliminar automáticamente objetos sin stock.
- **Reducir el uso de papel y errores humanos:** Evitar registros manuales impresos, mejorando la precisión y comodidad del usuario.
---
## Tecnologias Utilizadas
- XML
- Kotlin
- SQLite
